# 通用设计模板

这里用于沉淀不依赖特定公司或产品的可复用设计流程。模板不仅服务出图，也要形成可交接、可复现、可用于作品集的证据。

## 已有模板

- [设计任务卡模板](设计任务卡模板.md)：定义目标、输入、限制和交付。
- [AI 工作流实测卡](AI工作流实测卡.md)：记录环境、参数、三次运行、失败原因和质量检查。
- [作品集案例模板](作品集案例模板.md)：把项目整理为问题、判断、系统、结果和复盘。

## 建议目录

- 产品摄影与场景合成
- 海报与版式留白
- 局部重绘与材质探索
- 重打光与阴影融合
- 电商批量规格
- 修复放大与清晰化
- 图生视频与动态广告
- CMF 材质与工艺验证
- CAD/STP 与产品可视化
- 待验证

每个核心流程同时保存 JSON、任务卡、实测卡、输入输出示例和来源许可。不要提交客户原图、公司机密或模型权重。
