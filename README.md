# ComfyUI Design Workflow Library

一个面向视觉设计、产品展示与内容生产的 ComfyUI 工作流素材库。当前版本收录约 819 个可检索工作流，并为 AI 助手准备了任务标签、依赖信息、硬件参考、来源记录和本地检索工具。

这个仓库强调“先找到合适方案，再检查依赖，最后实测”，适合长期积累个人设计能力，不依赖某家公司或单一行业。

## 快速开始

1. 下载或克隆仓库。
2. 浏览器打开 `00_开始这里.html`，按设计任务搜索。
3. 阅读 `00_AI助手入口.txt`，让支持本地文件访问的 AI 助手推荐工作流。
4. 将选中的 JSON 拖入 ComfyUI，按照资料卡补齐模型和自定义节点。

命令行示例：

```powershell
python ".\05_知识库\tools\library.py" recommend "产品换背景并保留主体" --runtime local --limit 5
python ".\05_知识库\tools\library.py" search "扩图 留白 海报" --runtime local --limit 10
python ".\05_知识库\tools\library.py" get WORKFLOW_UID
python ".\05_知识库\tools\library.py" models "iclight"
python ".\05_知识库\tools\library.py" verify
```

## 适合的设计任务

- 产品海报、展会视觉与电商主图
- 抠图、换背景、局部重绘和扩图留白
- 材质、颜色、服装和表面效果探索
- Relighting、阴影融合、色彩匹配和图像修复
- 放大、锐化、去噪与细节恢复
- 参考图控制、姿态控制和构图迁移
- 图生视频、短片镜头、循环动画与分镜探索
- 批量出图、规格适配和品牌内容变体

## 使用边界

- 仓库不包含模型权重；模型文件通常体积较大，也可能有单独许可。
- “已收录”不代表已在你的机器上完成 GPU 实测。请查看资料卡中的验证状态。
- 部分流程依赖第三方自定义节点、云 API 或特定 ComfyUI 版本。
- 精确文字排版、品牌 Logo、包装文字和可交付矢量稿，建议在生成后使用确定性设计工具完成。

## 来源与许可

这是一个聚合与索引项目。第三方工作流、说明文档和示例仍受各自原始许可约束；来源信息保存在对应目录及 `90_来源与校验`。在商业项目或再次分发前，请检查具体来源的许可证。仓库没有用一个统一许可证覆盖所有第三方内容。
